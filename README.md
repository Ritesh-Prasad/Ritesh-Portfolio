# Ritesh Prasad | Cloud and DevOps Portfolio

A live portfolio website showcasing my Cloud and DevOps projects, technical skills, resume, certifications, and professional profile.

## Live Demo

[Visit Portfolio](https://www.riteshcloudops.online/)

## About the Project

This repository contains the source code for my personal portfolio website, built to highlight my profile as a Cloud and DevOps Engineer. The site is designed to help recruiters, hiring managers, and technical professionals quickly understand my background, skills, certifications, and project experience.

## Highlights

- Live personal portfolio website
- Hosted on AWS EC2
- Custom domain configured with AWS Route 53
- Resume and professional profile presentation
- Technical project showcase
- Skills in AWS, Jenkins, CI/CD, Linux, Nginx, and cloud technologies
- Certification and internship visibility
- Recruiter-friendly online presence

## Tech Stack

- HTML
- CSS
- JavaScript
- AWS EC2
- AWS Route 53
- Jenkins
- GitHub

## Repository Contents

- `index.html` — main portfolio webpage
- `style.css` — website styling
- `script.js` — client-side interactivity
- `Jenkinsfile` — CI/CD pipeline configuration
- `CNAME` — custom domain configuration
- Resume files — recruiter-ready resume versions
- `profile.jpg` — profile image used in the portfolio
- `internship-certificate.jpg` — certificate asset used in the portfolio

## Deployment

This portfolio is hosted on an AWS EC2 instance and mapped to a custom domain using AWS Route 53.

**Live URL:**  
[https://www.riteshcloudops.online/](https://www.riteshcloudops.online/)

## Purpose

The purpose of this project is to maintain a professional online presence and provide a single platform where recruiters, hiring teams, and professional connections can review my Cloud and DevOps profile, technical skills, projects, certifications, and resume.

## Use Case

This portfolio is intended for:

- Recruiters reviewing my profile
- Hiring managers evaluating my technical background
- Professionals interested in my Cloud and DevOps work
- Networking and career opportunities
